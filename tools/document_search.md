# 工具：document_search

> **⚠️ 说明文档：** 工具的实际代码在 `js/agent_tools.js` 中。修改此文件不影响智能体行为。

搜索已上传的知识库文档。当用户问到之前上传过的文档内容时自动调用。

## 触发条件

用户问"我的文档里关于...""之前上传的文献中..."等涉及已上传文档的问题时自动调用。

## 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| query | string | 是 | 搜索关键词或问题 |

## 搜索方式

纯向量语义搜索（正则模式已移除），使用文档上传时生成的 embedding 进行余弦相似度匹配。

## 返回格式

```json
{
  "count": 3,
  "data": [
    {"source": "论文1.pdf", "score": 0.85, "content": "相关正文片段..."},
    ...
  ]
}
```
