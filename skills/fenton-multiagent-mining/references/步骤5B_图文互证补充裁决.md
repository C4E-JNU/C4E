# 步骤 5B：图文互证补充 · 批次级矛盾裁决与定级

> **位置**：**紧随步骤五之后**（全批所有篇的图文互证收尾、`07_contradiction_ledger.json` 出齐后执行）——它是图文互证的**补充步骤**，不是独立环节。
> 前置：步骤五已产出候选矛盾（各篇 `07_contradiction_ledger.json`，`severity` 全空）
> 执行：**派 `fenton-arbiter`，每批次 1 个实例**（批次过大按污染物/主题分片）→ 主控落盘 + 脚本回写
> 为什么单列：步骤五判得出的是**篇内**发现项 Q；**跨文献矛盾要批次/全库视野、定级要统一口径**——分散在篇内判必然漂移。所以互证本身只出候选，裁决由本补充步骤一次做完。

## 派发

```
delegate_task(tasks=[
  {"profile": "fenton-arbiter",
   "goal": "对 <批次目录名> 的候选矛盾定严重度 A/B/C/D/E（判不了写 E）、定采纳值、判跨文献互斥与口径差，产出矛盾裁决 JSON",
   "context": "<批次目录路径>；篇级候选账在各 <论文夹>/datamining/07_contradiction_ledger.json；"
              "口径规范 skills/fenton-multiagent-mining/references/矛盾分类规范.md；批次篇数 N，逐篇覆盖不要漏"},
  # 每批次一条
])
```

**一个实例一个批次**（跨文献判定需要全批视野）；批次 > 15 篇时按污染物类别分片，
但**同一主题必须落在同一实例**，否则跨文献那一对判不出来 —— 分片时在 context 里写明「只判 XX 类，其余不判」。

## 裁决员做什么（详见其 `system.md`）

| 动作 | 产出字段 |
|---|---|
| 定严重程度 | `severity` ∈ A（数值偏差）/ B（条件归属错位）/ C（命名编号计数）/ D（结论被自身数据否定） |
| 定案 | `adopted_value` + `adopt_reason`（证据链：图内标注自洽 > 多面板收敛 > 质量平衡 > 正文多处一致） |
| 判跨文献 | `cross_paper=true` + `cross_paper_pairs[]{a,b,topic,conflict,severity,basis}` |
| 判口径差 | `caliber_variance=true` → 进 `caliber_only`，**不算矛盾** |
| 定不了的 | `severity="E"`（其他·无法归类） + `needs_human_review=true`（**不得硬判、不得留空、不得写 `unknown`**） |

判级前置（三条全满足）：① 非我方提取错（Q1/Q2 已排除）；② 非 OCR 伪影；③ 数值差 ≥5% 量程（或 5% 相对值，取大者）。

裁决员**只读不写**：它读 `07` / `04` / `04b` / `00_full_cleaned.md` / 面板图 / 图谱历史结论，
不需要 `06b_numeric_schema.json`（这也是本步能紧接步骤五、不必等到末尾的原因）。

## 主控收口

1. 把子智能体回报的 JSON **原样**落盘为 `<批次>/_ledgers/矛盾裁决.json`
   （单篇：`<论文夹>/datamining/_ledgers/矛盾裁决.json`；旧批次若仍是 `09_arbitration.json`，脚本会自动发现）；
2. 回写台账（纯脚本）：

```
python step5b_arbitrate_merge.py <批次目录> [--arbitration <裁决 JSON 路径>]
```

→ 回写各篇 `07_contradiction_ledger.json` 的 `severity` / `cross_paper` / `caliber_variance` / 定案 / 复核标记
→ 导出 `<批次>/_ledgers/全部矛盾条目.json`（`build_report.py` 的矛盾清单输入）
→ 导出 `<批次>/_ledgers/跨文献矛盾对.json`（跨文献对 + 口径差备注）
3. 存疑条目（`severity=E`）**逐条过目**：能补证据的自己补（回原文/回图），补不了的在报告里标「建议人工复核」。

## 核验

1. 裁决 JSON 可解析，`summary` 各级计数与 `entries` 实际条数一致；
2. **台账里 `severity` 无空值**（空的一律回填 `E`）、且**取值 ∈ A/B/C/D/E 五值**（出现 `unknown` 即口径违规）；
3. 每条 `severity ∈ A/B/C/D` 的都要有 `adopt_reason`；`E` 的要有 `needs_human_review=true`；
4. `cross_paper=true` 的条目必须在 `cross_paper_pairs` 里能找到对应的一对（含 `basis`）；
5. 匹配键一致：`(paper, figure, field)` 在台账与裁决里一一对应，脚本报「命中 N / 新增 M」中新增应为 0 或已解释；
6. 回写后 `07` 的 `by_severity` 计数 = `全部矛盾条目.json` 同严重度条数。

> **可复跑**：若步骤五及更早步骤重跑导致 `07_contradiction_ledger.json` 重新生成，本步须重跑（幂等，重跑只覆盖 `severity` 系列字段）。
