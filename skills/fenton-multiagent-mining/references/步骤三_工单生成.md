# 步骤三：工单生成

> 前置：步骤二完成——`datamining/00_full_cleaned.md` + `datamining/images/` 就绪
> 执行：每篇 1 个 `fenton-workorder`（同档案可多实例并行）
> 子智能体只读；结论由主控落盘 `datamining/01_work_order.json`

把已归档的论文文件夹交给 `fenton-workorder`，它通读全文、**逐子图**判定数据价值，
打包成提取工单，决定后续提取器要处理哪些图。

## 派发

```
delegate_task(tasks=[
  {"profile": "fenton-workorder",
   "goal": "生成工单：读全文识别有数据提取价值的图像，逐子图判定价值与 needs_xy_extraction，打包成 01_work_order.json",
   "context": "<论文文件夹路径>"},
  # 每篇一条
])
```

## 子智能体回报格式

回报 JSON 的**字段定义与示例见** `backend/agents/fenton-workorder/system.md`（唯一载体，本文件不重复）。
主控只核两样：每个子图都有 `needs_xy_extraction` 布尔值（图级不得出现）、`summary` 四项与 `figures` 自洽。

## 主控收口

1. 逐篇落盘 `01_work_order.json`；
2. 汇总各篇 `summary` 写 `<语料根>/workorder_summary.json`；
3. `failed / partial` 按纪律重派（同一子任务最多 2 次）。

## 核验

1. `01_work_order.json` 存在且可解析；
2. `summary` 四项与 `figures` 自洽：`figures_xy_total` = 含 ≥1 个 XY 子图的图数，`figures_split_total` = 收录图数，`subfigures_xy_total` = XY 子图数，`extraction_calls_total` = 收录子图总数；
3. 每个子图都有 `needs_xy_extraction` 布尔值，且图级不出现该字段；
4. 纯装饰示意图未被收录、表格未被收录、3D 曲面未收录。
