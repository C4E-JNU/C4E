> 前置：步骤四完成——`03_image_data.json` 已汇总
> 执行：每篇 1 个 `fenton-verifier`（阶段一 + 二合一）→ 主控组装 + 脚本
> 产出：**互证发现项 Q1–Q4 + 候选矛盾**。**本步不定严重程度**——A/B/C/D/E 由紧随本步的 **步骤 5B** `fenton-arbiter` 批次级判定
> 口径：`references/矛盾分类规范.md`（唯一来源）

## 派发

```
delegate_task(tasks=[
  {"profile": "fenton-verifier",
   "goal": "图文/表文互证 + 候选矛盾清扫：判 Q1/Q2/Q3/Q4（我方读图错/读文错/口径差/一致），"
           "对排除后的候选矛盾只给证据、severity 留空，并给采纳建议",
   "context": "<论文文件夹的 datamining 目录路径>；口径 skills/fenton-multiagent-mining/references/矛盾分类规范.md"},
  # 每篇一条
])
```

## 子智能体回报格式（四块，**不要回贴全量 04 副本**）

1. 逐条**标注表**（`figure / subfigure / source / checked / value_source / finding`，覆盖全部记录一条不漏）
2. `04_internal_corrections.json`（Q1/Q2 —— 我方提取错误，不入矛盾库）
3. `04_discrepancy_ledger.json`（候选矛盾，**severity 留空**）
4. `04b_text_table_contradictions.json`（正文/表格候选矛盾，**severity 留空**）

四块的**字段定义与示例见** `backend/agents/fenton-verifier/system.md`（唯一载体，本文件不重复）；
`severity` 一律为空串，`evidence_source` 只取四个合法值。

> `04_verified_image_data.json` 是 `03_image_data.json` 的**全量副本**，体积远超单次回喂上限，
> 主控脚本用标注表把 03 复制成 04（匹配键 `(figure, subfigure)`），**必须保留全部 `curves[].points[]`**
> ——下游 schema 填充子智能体从这里按 `(figure, subfigure) + curve_label` 逐条取点并写入曲线片段文件（不经聊天回贴，无截断）。

## 主控收口

1. 落盘：标注表存 `datamining/04_annotation_table.json`，另三个 JSON 原样存为
   `04_internal_corrections.json`（Q1/Q2）、`04_discrepancy_ledger.json`（候选矛盾）、
   `04b_text_table_contradictions.json`（文/表候选矛盾）；
2. 组装：用标注表把 `03` 复制成 `04`（保留全部 `curves[].points[]`）

```
python step4_assemble_verified.py <论文文件夹或批次根>
```

3. 终审：逐条核对候选矛盾的 `adopted_value` 方向；OCR 存疑条目对照 origin PDF **文本层**；
4. 出账（**归一旧口径 + 出互证收益**）：

```
python step4c_errata.py <论文文件夹或批次根>
```

→ `07_contradiction_ledger.json`（篇级候选账，`severity` 空/E 待回填）
→ `04c_errata.json`（Q1/Q2 我方提取错误）
→ `05b_verification_gain.json`（篇级）+ `<批次>_互证收益汇总.json`（批次级 C/e/R/Δ）

> **严重度不在此步定**：`07` 里的 `severity` 由紧随本步的 **步骤 5B** `fenton-arbiter` 回填，
> 再跑 `step5b_arbitrate_merge.py` 合并（见《步骤5B_图文互证补充裁决.md》）。
> 三个脚本都在本技能包 `scripts/` 下；传单篇论文夹或批次根都可以（自动识别）。

## 核验

1. `04_verified_image_data.json` 是 list 全量副本（非 dict），`curves[].points[]` 点数与 03 逐点一致
   （组装脚本打印 `曲线点 N/N OK`，不等即失败）；
2. 组装脚本报「未标注」为空（标注表覆盖 03 全部记录）、「标注表多余」为空（无对不上的键）；
3. 三个 JSON 无重叠条目：**Q1/Q2 只在 `04_internal_corrections.json`；Q3 落在 `04_discrepancy_ledger.json` 且 `caliber_variance=true`（主控抽到 `caliber_only`，不计入矛盾）；Q4 只在标注表**；
4. 候选矛盾里 **`severity` 全为空串**（出现 A–E 任一值即为越权 —— 定级是步骤 5B 的职责）；
5. `evidence_source` 全部落在四个合法值内（`text-vs-figure` / `text-vs-table` / `text-vs-text` / `figure-vs-table`）；
6. OCR 伪影已剔除（存疑条目已核 PDF 文本层）；
7. 抽查若干候选：`adopted_value` 与证据链一致、`confidence` 与实际把握相符；
8. 互证收益已出：`05b_verification_gain.json` 里 `N` > 0、`checked ≤ N`，`Δ = fixed / N` 与 `fixed`/`e` 自洽；
9. **端点回填**（`finding.endpoint_backfill`）只出现在标注表（Q4 法定居所），逐条带 `points_after` 且点位数
   与图账该曲线一致（仅终点值被正文值替换）；`04_internal_corrections.json` 无 Q4 条目（有则会被 `step4c` 误归成 Q1/Q2）。
