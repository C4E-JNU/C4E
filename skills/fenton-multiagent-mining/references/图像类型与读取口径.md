# 图像类型与读取口径（普查版参考）

> 本文件按非均相 Fenton 数据挖掘目标整理 107 个图像类型的处理口径，依据 1,078 篇文献、9,314 幅图像的普查结果与现行工单/图像提取提示词。
> 仅用于文档与复核，不参与运行时派发；运行判据以 `backend/agents/fenton-workorder/system.md` 与 `backend/agents/fenton-image/system.md` 为准。

## 收录判定（与工单一致，逐子图）

1. **体系匹配**：催化剂为固体金属位点的非均相 Fenton / 类 Fenton 体系；不符合的部分不收。
2. **有增量数据**：子图须含可提取的数值或谱图要点，且正文未完整给出。若正文已说明形貌、颜色、结构等，图像只是示意或重复，则不收。
3. **可读取**：当前视觉模型无法可靠读取的复杂三维曲面、复杂分子式等不收。
4. **子图级**：一子图一判；同图可有收有不收。表格不入图像工单，由 MinerU 解析。

## 处理方式代码

| 代码 | 含义 | 读取规则 |
|---|---|---|
| XY | 逐点读轴（xy） | 先读轴标签、单位与量程，再逐点估读全部可见点（含起点、终点）；同面板多曲线并入一条记录。 |
| B | 要点读取（basic） | 按该类型的要点清单取值，数值带单位；谱图记峰位/归属，统计图记条目/数值。 |
| E | 不收录 | 不进入工单：示意图、流程图、照片、分子结构式、三维曲面，或正文已完整给出而图像无增量。 |

说明：同一类型若同时包含有数据面板与纯示意面板，代码给出有数据面板的默认口径，具体由工单在子图级裁定。
