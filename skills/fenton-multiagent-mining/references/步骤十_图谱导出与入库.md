## 命令

```
python step10_graph_export.py <语料根 或 论文文件夹> [--batches B01 B02]
python step11_neo4j_import.py <graph_export 目录> [--dry-run] [--purge-export | --purge-batch B101 | --purge-paper 论文夹] [--no-embed]
python step12_table_export.py <语料根 或 graph_export 目录>
python export_audit.py <graph_export 目录> --root <语料根> [--neo4j]   # 导出后覆盖自检（必跑）
```

脚本在本技能包 `scripts/` 下，连接参数读 `scripts/neo4j.env`。

| 参数 | 作用 |
|---|---|
| `--batches` | 只导指定批次；省略 = 全部 `Bxx` |
| `--dry-run` | 只核对计数、不实写（**首次或换语料必先跑**） |
| `--purge-export` | 入库前清**本导出目录所含论文**的旧节点（按 dir_name 反查新旧全部 paper_id）—— **重导标准动作** |
| `--purge-batch` / `--purge-paper` | 按批次名 / 论文夹名清理旧节点（跨批次重排时用） |
| `--no-embed` | 跳过向量生成（仅调试用） |

> **【2026-10-09 新 schema 兼容已验证】**：步骤七三元组直出（{value, unit, raw}）、嵌套 levels
> （metric_value 为三元组）、曲线绑定带 x_unit/y_unit——导出脚本原生吃这套结构
> （`flatten_num` 展平三键、变量水平展开 `E1::V1::L2`、`build_curve` 透传坐标单位），合成批次
> 冒烟测试全绿，无需任何补丁。

## 十① 导出（step10 → `<语料根>/graph_export/`）

读每篇 `<datamining>/06b_numeric_schema.json`（缺则回退 `06_schema.json`）+ `07_contradiction_ledger.json`，
外加 `_ledgers/<批次>_污染物对齐表.json`（步骤六产物）；**实体信息在这一步一次做完**，不再另跑补丁脚本。

| 节点 | 唯一键 | 来源与要点 |
|---|---|---|
| Paper | `paper_id` | metadata + 矛盾计数 + `contradiction_severity` 摘要串（如 `A1 B2 E1`）+ `search_text` |
| Catalyst | `pid::C序号` | **跨文献不合并**；数值扁平三键 `<field>` / `<field>_unit` / `<field>_raw`（单位与原文永不丢）；另算 `material_family` / `loading_pct` 作**聚合键**，并生成 `search_text`（供 `vec_catalyst`） |
| Experiment | `cid::E序号` | experiments[]，文本原样、数值三键；**stability 6 键以 `stability_<field>` 前缀扁平入节点**（不再整段丢）；生成 `search_text`（供 `vec_experiment`） |
| Variable | `eid::V序号::L水平序` | variable_experiments[].levels[] **逐水平展开**（v2，2026-10-07）：节点带 `variable_parameter` / `level_value`（水平值）/ `metric_name` / `metric_value` / `fixed_conditions` / `level_index`，数值均为扁平三键；「pH=3 时 TOC 去除率」一句 Cypher 可查。旧篇无 `levels` 时回退 `eid::V序号` |
| Curve | `eid/vid::Q序号` | degradation_profiles（xs / ys / metric / 单位 / source_figure / `curve_label` / `n_points`） |
| Contradiction | `pid::K序号` | 07 裁决后账目：`severity`（A/B/C/D/E，**E = 其他·无法归类**，兼待裁决）+ `severity_label`（中文全称）+ `evidence_source`（text-vs-figure / text-vs-table / text-vs-text）+ `cross_paper` / `caliber_variance` 两个布尔 + 正文值/图值/裁决值/理由/置信度 + **`trace`**（`paper_id / 标题 / 字段 / 图号` 一行直读）。`needs_human_review = (severity=E or cross_paper)`。**旧 `category` 属性已废弃，`unknown` 已退场** |
| Entity | `POL::` | Pollutant：join 对齐表 → CID / 分子式 / 分子量 / InChIKey / CAS |
| Figure | `FIG::<paper_id>::FigureN` | **按论文限定**（旧版 `FIG::Figure5` 全局共享会跨篇串台）；带 `paper_id` / `figure_no` / `name` |

边：`HAS_CATALYST` `USES_CATALYST` `DEGRADES` `HAS_VARIABLE` `HAS_CURVE` `FROM_FIGURE` `DISPUTES` `FROM_EXPERIMENT` `DISPUTED_IN`。

矛盾的**三层锚点**（溯源要求：每条矛盾必须能定位到文献，能则到实验/图）：

| 边 | 指向 | 覆盖 |
|---|---|---|
| `DISPUTES` | Paper | **必连，100% 零孤儿** —— 任何一条矛盾都能直达所属文献 |
| `FROM_EXPERIMENT` | Experiment | 尽力而为：该篇实验节点唯一且字段可判定，或污染物名唯一命中 |
| `DISPUTED_IN` | Figure | 图号可解析（`Fig.5` / `Figure S3`）时建立 |

产物：`nodes_paper / nodes_catalyst / nodes_experiment / nodes_variable / nodes_curve / nodes_contradiction / nodes_extra .json` + `edges.json` + `manifest.json`。

## 十② 入库（step11）

- 按唯一键 **MERGE（幂等，可反复重跑）**，建约束与索引（含 5 个向量索引：`vec_paper` / `vec_catalyst` / `vec_experiment` / `vec_contradiction` / `vec_entity`）；
- **写入语义：`SET x = $props`（先清后写）** —— 旧版 `SET x += $props` 只增量覆盖，
  上游已删字段会以脏属性形式留在节点上（重跑后图谱与源数据不一致）；
- **边属性必须写**（2026-10-10 修 / P0）：MERGE 关系后补 `SET r = $props`。旧版只建边不写属性 →
  `DEGRADES.pollutant` 等**边的属性 100% 丢失**（实测 B101：34 条 DEGRADES 带 pollutant 者 0 条）；
- **嵌套数组序列化**：曲线点位 `xs` / `ys` 是嵌套数组，Neo4j 属性不支持 →
  自动转 `<key>_json` 字符串 + `<key>_n` 计数（**点位不再丢**；实测旧版 5586 个 Curve 节点 0 点位）；
  混合类型数组（`['Fe', 1]`）同样序列化 —— Neo4j 拒收，旧版会让整批写入中断；
- 边两端节点缺失时自动建 Entity / Figure 兜底 → 零孤儿，**且逐条记入报告**（不静默丢边）；
  单条边异常 try/except 记 `skipped` 后继续，不再半写入无报告；
- 写入后**边对账（含本批视角）**：按类型统计全库 + **本批端点过滤**两套边数，
  后者与 `edges.json` 期望值应严格相等（全库视角会被历史数据掩盖，不能作判词）；
- 顺带补齐 `embedding`（bge-small-zh-v1.5，512 维；已有自动跳过）—— Catalyst / Experiment /
  Contradiction / **Entity（Pollutant）** 均有 `search_text`，五个向量索引不再空转；
  **跳过时报告必须说实话**：fastembed 缺失 / 模型加载失败（如**本机无外网且无本地缓存**，
  实测 26s ConnectTimeout）会跳过嵌入，但报告如实落 `embedded_pending`（真实待嵌入数）与
  `embed_skipped: true` —— 旧版此时 `embedded_pending` 报全 0，与「已全部嵌入」无法区分，
  实测把 4064 个待嵌入节点（Paper 199 / Catalyst 1035 / Experiment 1543 / Contradiction 940 /
  Entity 347，全库口径）误报成「无待嵌入」。恢复网络后去掉 `--no-embed` 重跑即补嵌
  （注意 `embed_pending` 是**全库**范围，不只本批）；
- 落盘 `graph_export/_import_report.json`（节点/边计数、`edges_reported_batch`、
  `edge_props_expected/written`、`purged`、跳过边、唯一键重复、被序列化的键、嵌入统计）；`--dry-run` 落 `_import_report.dryrun.json`；
- **这是全流程唯一写 Neo4j 的入口**。

> **【2026-10-10 起：入库前必清同批旧节点 → 用脚本参数，不再手写 Cypher】**
> MERGE 按 node_id 幂等，但 **paper_id 是内容哈希**（`P_` + md5(论文夹路径)），步骤十规则一变就换 id，
> schema 改版后新旧 node_id 又不同（如变量 `E1::V1` → `E1::V1::L2`）——**唯一键 MERGE 完全挡不住
> 「同篇两套节点并存」**（实测 B101：Paper 10≠5、Experiment 68≠34、Catalyst 42≠21、Curve 124≠88）。
> 标准动作是重导前加 `--purge-export`：脚本按 `dir_name` / `batch` 反查**新旧全部** paper_id
> 再 `DETACH DELETE`（旧 id 的遗留节点一并清掉；Entity/Pollutant 是跨篇共享实体，无 paper_id，按设计保留）。
> 清理范围会打印，并写入报告的 `purged`；`--dry-run` 可先看计数。
> 导入后用 `validate_sop_export.py` + `export_audit.py` + 实库属性回查（node 全量比 key/value，`''≈None`）做零丢失判词。
>
> **【不落痕验证法】**改过 step11 后想验证"写进去到底丢不丢"又不想动远端库：
> 用**事务回滚探针**（`output/verify_v5/tx_probe2.py` 可作模板）——`session.begin_transaction()` 里
> 复用 `step11` 的 `clean()/uid_of()/purge_scope()` 走完真实写入路径，回查边属性/节点数后 `rollback()`。

## 十③ 表格导出（step12_table_export.py，纯本地）

图谱之外的第二交付物：把 `graph_export/` 的节点 JSON 转成一张多 sheet Excel——
**论文 / 催化剂 / 实验 / 变量水平 / 曲线 / 矛盾** 六张表，与图谱同源同键（不会两边不一致）。

**【2026-10-09 v2 · 保三元组结构 + 曲线内嵌】**：

- 【数】字段出**三列**：`{字段}`（纯数字）/ `{字段}·单位` / `{字段}·原文`（raw 保真）——
  与图谱扁平三键一一对应，**不合并成「数值+单位」一格**；【文】字段单列文本；
- 列 = SOP 全字段（催化剂 45 / 实验 41+6）+ `other_` 兜底列动态收列；空格 = 论文未报道（blank 口径）；
- **曲线内嵌回实验行与变量水平行**：图例 / 单位(x/y) / 点数 / 点位紧凑串（`0,0;30,20;…`）直接挂在
  归属行上，变量水平行可直读「该水平 ↔ 该曲线」；曲线独立目录表（6 列 + 点位）保留作平铺目录；
- 用法：`python step12_table_export.py <语料根 或 graph_export 目录>` → 产 `graph_export/tables.xlsx`。

**【2026-10-10 v3 · 六表统一兜底列，堵「有值无列」】**（旧版只有变量表有兜底列）：

- 论文 / 催化剂 / 实验 / 曲线 / 矛盾五张表也补**动态兜底列**：白名单外的标量键一律以 `{key}(其他)` 出列
  （实测旧版丢：实验表 `other_*` 8 格 + `qc_*`、催化剂表 `catalyst_name` 21 条、矛盾表 `review_status`/`review_scope` 30 处）；
  三元组伴随键（`_unit`/`_raw`/`_range`/…）视为已承载，不重复出列；
- 矛盾表补 `review_status` / `review_scope` 列，实验表补 `catalyst_name` 列；点位 cap 40 → 200（长曲线不再截断）；
- `load()` 遇缺文件/解析失败**显式告警**（旧版静默 `[]` → 整表空且无人知）；
- 出表后落 `graph_export/columns_audit.json`（各表行数 / 兜底列清单），**兜底列非空即提示 schema 契约已演进**。

## 十④ 导出后覆盖自检（export_audit.py，必跑）

> 成品终检只保证「06 文件自身字段合规」，**不保证跨表示映射无损**；step10/12 的搬运层各含硬编码假设
> （去重签名、字段 merge、列白名单），契约一演进就静默过期。本步用**差集**把这条缝焊上。

- **A 行数**：每类节点数 ↔ 对应 sheet 数据行数（严格相等）；
- **B 列覆盖**：节点**每个键**必须落到某列 —— 白名单字段 → 其表头列；白名单外 → 兜底列 `{key}(其他|var)`；
  差集非空即 FAIL（这就是「字段没问题但导出丢」的通用探针）；
- **C 曲线三方**（需 `--root`）：06 源曲线（按「图号含子图 + 图例」去重）↔ `nodes_curve.json` ↔ 曲线 sheet 行数；
  标签也不在图谱 = **真丢（FAIL）**；标签在、仅图号不同（如 `Fig.1, Fig.3` 多图写法）= 差异提示不计 FAIL；
- **D 点位**：带 `xs` 的 Curve 数 ↔ 曲线表点位非空行数；`n_points` 总和一致；
- **E 实库**（`--neo4j`，可选）：按**本批归属**回查 —— 节点存在性（全类 `node_id` 全集）/ Paper 数 /
  关系数 / **带属性边数**（与 `edges.json` 期望值对账）/ 属性 key 数。
  边按**任一端**归属本批判定（另一端允许是共享 Entity / Figure 占位）—— 旧版要求**两端都命中**，
  连向 Entity 的 `DEGRADES` 边被整片漏统计（实测 B101：368 条只报 331、34 条带属性边报 0，
  这道门等于失效）；另按 `dir_name` 反查库里该篇**全部** `paper_id`，多于本批即判
  「同篇多套并存 → 需 `--purge-export`」（`paper_id` 是内容哈希，只按本批 pid 查不出来）；
- 输出 `graph_export/export_audit_report.json` + 控制台 PASS/FAIL，**FAIL 不得进入交付**。

## 图谱连接注意（远端 Aura）

图谱跑在**远端实例**，空闲回收连接：**首次或第二次调用可能失败**（`defunct connection`），
工具自带自愈重连 + 重试一次；脚本侧同样重试 3 次。
**一次失败 ≠ 图谱损坏、≠ 库里没数据** —— 再调一次即可，不要据此断言数据缺失。

## 核验

1. `manifest.json` 计数与各 `nodes_*.json` 实际条数一致；
2. 边文件里 **from/to 全部可解析**（无悬空引用）；`orphan` 边已标记；
3. 每个节点的唯一键**非空且批内无重复**；Catalyst 无 `node_id` 跨文献重合；
4. `--dry-run` 报的 `MERGE` 节点 / 边数与 manifest 一致后，才实写；
5. 实写后抽查：`MATCH (n) RETURN labels(n), count(*)` 与预期增量一致，约束 / 索引已建；
6. **数值三键抽查**：Catalyst / Experiment 上 `<field>_unit` 与 `<field>_raw` 齐全（例：`pore_size=18.5` + `pore_size_unit='nm'` + `pore_size_raw='…主峰约 17-20 nm'`），
   `<field>_unit` 个数 = `<field>` 个数（无单位字段除外）；Curve 有 `n_points` 且 `xs_json` 非空；
7. `_import_report.json` 的 `skipped_edges` / `dup_keys` 为空（非空须逐条说明原因）；
8. **`edge_props_written` = `edge_props_expected`**（边的属性不是可选项 —— 旧版全丢）；
9. **`edges_reported_batch` 与 `edges_expected` 严格相等**（本批视角，不受历史数据掩盖）；
10. `export_audit.py` 报 **PASS**（行数 / 列覆盖 / 曲线 / 点位四项零差集）——加 `--neo4j` 时还须
    「节点 N/N · Paper N/N · 关系 N/N · 带属性边 N/N」四项全等、且**无「同篇多 paper_id」告警**；
    曲线身份键**含子图字母**（`Fig.4B ≠ Fig.4C`），若用旧口径按数字去重，同图不同子图的同名曲线会被静默吞掉。
