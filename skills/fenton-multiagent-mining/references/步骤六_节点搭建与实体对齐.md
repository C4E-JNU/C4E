> 前置：步骤 5B（图文互证补充）完成（`04_verified_image_data.json` + `04c_errata.json` 就绪、`07_contradiction_ledger.json` 的 `severity` 已回填）
> 执行：每篇 1 个 `fenton-node`（节点清点）→ 主控脚本（实体对齐）

## 派发

```
delegate_task(tasks=[
  {"profile": "fenton-node",
   "goal": "节点清点：通读全文，清点催化剂/污染物/实验/变量四层节点骨架；变量登记参数名 + declared_levels（作者扫了哪些水平，逐个值列出），不填水平对应的指标值",
   "context": "<论文文件夹路径>"},
  # 每篇一条
])
```

可选：**全批共用 1 个实例**做材料族归并（读全批 `05_node_inventory.json`，输出材料族清单供人工复核）。

## 子智能体回报格式

回报 JSON 的**字段定义与示例见** `backend/agents/fenton-node/system.md`（唯一载体，本文件不重复）。
主控只核：四层引用完整、变量登记了参数名 + `declared_levels`（逐个值，不是一句叙述）、一实验一污染物、每个节点都有 `evidence`。

## 主控收口

1. 逐篇落盘 `05_node_inventory.json`（JSON 原文 + `_meta`：agent/status/confidence/rounds/tools_used）；
2. 跑 `step5b1_pollutant_align.py <论文夹 或 批次根>` 做实体对齐（单篇 / 批次自适应）：

| 产物（台账目录下） | 内容 |
|---|---|
| `<批次>_污染物对齐表.json` | 污染物 → CID / 分子式 / 分子量 / InChIKey / CAS（步骤十导出 join 用） |
| `<批次>_催化剂对齐表.json` | 催化剂 → 族键 `material_family` + 同族已入库节点 |
| `<批次>_实体对齐表.json` | 上述汇总 + `summary`（命中数、待合并数） |

台账目录：单篇 `<篇>/datamining/_ledgers/`；批次 `<批次根>/_ledgers/`。
可选参数：`--no-net`（只用图谱不联网）、`--dry-run`（只匹配不落盘）。

## 对齐口径（两类实体口径不同，勿混用）

- **污染物**（种类有限、跨文献同一物质）——**以收敛到同一节点为目标**：
  ① 先查图谱已有节点（归一化名 / 英文名 / 缩写展开匹配）→ 命中即复用其 CID / CAS / InChIKey，
  跨文献一致且省联网；② 未命中 → PubChem → NCI CACTUS 兜底。
  对齐表里 `graph_hits > 1` 表示库内同一物质已裂成多个节点（历史债、待合并，**不阻断流程**）。
- **催化剂**（变体极多：负载量 / 掺杂比 / 载体各异）——**不合并节点**：
  只算材料族骨架 `material_family` 作族键（算法与步骤十导出严格一致），记录同族已入库节点。
  跨文献用法 = 按族聚合、按变体区分：
  `MATCH (f {material_family:'Fe3O4'})…` 逐变体对比，而不是把变体并成一个。

## 坑

- 图谱是**远端 Neo4j**，空闲会回收连接 → 首次调用可能失败。脚本已自动重试 3 次；
  仍失败就稍后再跑，**不要据此断言图谱没数据**。
- 污染物节点标签是 `:Entity {label:'Pollutant'}`，**不是** `:Pollutant`。

## 核验

1. 催化剂 / 污染物 / 实验三层引用关系完整；
2. 变量登记了参数名与 `declared_levels`（逐个水平值），**没有**水平对应的指标数值（那是步骤七的活）；
3. 一实验一污染物（无并列串）；
4. 每个节点都有 evidence（章节定位）；
5. 三份对齐表齐备；污染物无 `unresolved`（有则人工换同义词重查）；催化剂 `family` 全部非空。
